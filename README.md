# 50 Startups Profit Prediction

## Project Overview

This project focuses on predicting startup profit using machine learning regression techniques.

The dataset contains information about 50 startups located in **New York, California, and Florida**, including their spending on R&D, administration, and marketing.

The project covers the complete basic machine learning workflow, including data exploration, preprocessing, regression modeling, model evaluation, and interpretation of results.

---

## Project Objective

The main objective is to build and evaluate regression models that can predict a startup's **Profit** based on:

- R&D Spend
- Administration Spend
- Marketing Spend
- State

Two regression models were evaluated:

- Linear Regression
- Decision Tree Regressor

---

## Dataset

The dataset contains **50 observations and 5 variables**.

| Feature | Description |
|---|---|
| R&D Spend | Amount spent on research and development |
| Administration | Administrative expenses |
| Marketing Spend | Marketing expenses |
| State | Location of the startup |
| Profit | Startup profit — Target variable |

### Data Quality

The initial data inspection showed:

- 50 startup observations
- No missing values
- No duplicate records
- Four numerical variables
- One categorical variable

---

## Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed to understand the distributions, relationships, correlations, and potential outliers in the dataset.

### Main EDA Findings

- **R&D Spend** showed the strongest positive relationship with Profit, with a correlation of approximately **0.97**.
- **Marketing Spend** also showed a strong positive relationship with Profit, with a correlation of approximately **0.75**.
- **Administration Spend** showed only a weak relationship with Profit.
- The three states were almost equally represented in the dataset.
- Profit distributions across states overlapped substantially, suggesting that State may have less predictive influence than R&D Spend.
- R&D Spend and Marketing Spend had a correlation of approximately **0.72**.

### Outlier Analysis

The IQR method was used to investigate potential outliers.

No outliers were detected in:

- R&D Spend
- Administration
- Marketing Spend

One potential outlier was detected in Profit.

The observation had a profit of approximately **$14,681**, slightly below the calculated IQR lower bound. However, the observation was retained because its low profit was consistent with its zero R&D spending and relatively low marketing spending.

---

## Data Preprocessing

Before model training, the dataset was divided into training and testing sets using an **80/20 split**.

The following preprocessing steps were applied:

### Numerical Features

`MinMaxScaler` was applied to:

- R&D Spend
- Administration
- Marketing Spend

### Categorical Feature

`OneHotEncoder` was applied to the `State` variable.

The first category was dropped to avoid redundant dummy variables, and unknown categories were handled safely during transformation.

---

## Models

### 1. Linear Regression

Linear Regression was used as the first regression model to predict startup profit.

### 2. Decision Tree Regressor

A Decision Tree Regressor was trained as an alternative non-linear regression model.

The tree was limited to:

```python
max_depth=5
```

to control its complexity.

---

## Model Evaluation

The models were evaluated using three regression metrics:

- **MAE — Mean Absolute Error**
- **RMSE — Root Mean Squared Error**
- **R² — Coefficient of Determination**

### Results

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| **Linear Regression** | **6,961.48** | **9,055.96** | **0.899** |
| Decision Tree | 9,979.53 | 12,679.07 | 0.801 |

### Model Comparison

Linear Regression achieved:

- Lower MAE
- Lower RMSE
- Higher R²

Therefore, **Linear Regression was selected as the better-performing model** for this dataset.

The Linear Regression model explains approximately **89.9% of the variation in Profit on the test set**.

---

## Actual vs Predicted Profit

The actual profit values were compared with the predictions generated by the final Linear Regression model.

Most predictions were relatively close to the actual values and appeared near the ideal prediction line.

However, larger prediction errors were observed for a few startups, particularly among some of the lower-profit observations.

---

## Residual Analysis

Residuals were calculated as:

```text
Residual = Actual Profit - Predicted Profit
```

The residual plot showed observations on both sides of zero without a clear systematic pattern.

This suggests that the Linear Regression model does not show an obvious systematic prediction bias on the test data.

However, some relatively large residuals were observed.

Since the test set contains only **10 observations**, the residual analysis should be interpreted with caution.

---

## Key Findings

- R&D Spend was the feature most strongly associated with startup Profit during EDA.
- Marketing Spend also had a positive relationship with Profit.
- Administration Spend showed a relatively weak relationship with Profit.
- State appeared to have less influence on Profit compared with R&D spending.
- Linear Regression performed better than the Decision Tree Regressor.
- Linear Regression achieved a test **R² of 0.899**.
- The final model achieved an **MAE of $6,961.48** and an **RMSE of $9,055.96**.
- Most predicted values were reasonably close to their actual values.

---

## Limitations

The dataset contains only **50 startups**, which limits the amount of data available for model training and evaluation.

The test set contains only **10 observations**, meaning that the evaluation results may be sensitive to the particular train-test split.

Additionally, only a limited number of business-related features are available in the dataset. Other factors that may influence startup profitability are not represented.

Therefore, the model's performance should not be assumed to generalize to all real-world startups.
